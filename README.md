# Drive-Thru Pace

Phone timer for a drive-thru shift leader. Open it, tap as cars pass.

1. **Car here** — car is at the window, 30-second clock starts
2. **Pulled off** — car left, time is saved, ready for the next one

That is the whole job. Add to Home Screen on a phone so it opens like an app and the screen stays awake.

## Live

https://roudic.github.io/drive-thru-pace/

## Extra

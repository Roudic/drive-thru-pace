# Drive-Thru Pace

Phone timer for a drive-thru shift leader. One button: **Pull off**.

Tap every time a car leaves the window. The next car’s 30-second clock starts by itself.

Add to Home Screen on a phone so it opens like an app and the screen stays awake.

## Live

https://roudic.github.io/drive-thru-pace/

## Extra

- Lane 1 / Lane 2 at the top
- **Undo** if you tapped too soon
- Menu: sound, voice alerts at 25 / 27 / 30, shift stats, export CSV, new shift
